# Laboratorio de organización de archivos

Cuatro ejercicios interactivos sobre índices invertidos, consultas booleanas, palabras vacías y metadatos. Abra `index.html` en un navegador o visite la versión publicada en GitHub Pages. Cada pestaña incluye datos de ejemplo. Los datos permanecen en memoria durante la sesión y se pierden al recargar.

Las búsquedas normalizan mayúsculas y tildes. La búsqueda del índice y la de palabras vacías devuelven documentos que contienen al menos un término; los filtros de metadatos se combinan con AND.
